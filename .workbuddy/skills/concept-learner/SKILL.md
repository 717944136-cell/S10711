name: concept-learner
description: 接收任意学术或技术概念作为输入，生成结构化的个人学习资料（HTML 格式），包含个人化解释、核心机制、应用场景、概念辨析和可核查来源。适用于构建个人知识库和学习笔记。
---
## 适用场景
- 学习一个新的技术或学术概念
- 构建个人知识库的条目
- 复习时快速生成结构化笔记
## 输入信息
- 一个概念名称（必填）
- 可选：学习者已有知识背景简述
- 可选：期望的输出深度（入门/进阶/深入）
## 生成步骤
1. 确认概念的定义边界，区分其核心含义与相关但不相同的概念
2. 梳理该概念的核心机制或组成要素
3. 构思一个具体且贴近实际的应用场景
4. 识别学习者容易混淆或误用的边界情况
5. 检索可核查的公开资料来源（官网、学术论文、权威文档）
6. 按输出结构组织内容
## 输出结构
生成一份完整的 HTML 文档，包含以下区块：
- 概念的个人解释：用自己的话重新表述，避免直接复制定义原文
- 核心机制或组成：拆解该概念的关键部件或工作原理
- 具体应用场景：一个真实或贴近真实的场景描述
- 容易混淆的问题或使用边界：至少 3 条辨析
- 可核查的资料来源链接：至少 3 个，需是可公开访问的真实 URL
- 自测问题：3 个帮助检验理解的问题
## 资料来源要求
- 必须使用真实存在且可访问的 URL
- 优先使用官方文档、学术论文、权威技术博客
- 禁止编造链接
- 如果无法确认某个来源的真实性，宁可减少来源数量
## 自检要求
生成后逐项检查：
- HTML 结构完整，可在浏览器正常打开
- 每个区块内容充实，无空泛套话
- 来源链接真实可访问
- 解释为个人化表述，非整段照搬
- 概念辨析准确，没有事实性错误
