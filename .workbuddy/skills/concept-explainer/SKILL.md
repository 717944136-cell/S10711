# concept-explainer：概念学习资料生成器

> 把"我学懂一个概念"变成一套可复现、可核查的流程。
> 作者：S10711（个人学习 Skill，迭代维护中）

## 1. 适用场景

本 Skill 用于**把任何一个新概念学成一份结构化学习资料**，适合：

- 课程/自学中遇到新概念（如 Transformer、RAG、提示词工程、MCP……）；
- 准备用"费曼学习法"检验自己是否真的理解某概念；
- 需要为某概念准备一份能放进作品集的说明文档。

**不适用**：闲聊式的一问一答；不需要生成资料、只想要一句话解释的即时提问（那种直接回答即可，不必调用本 Skill）。

## 2. 输入信息

一次调用只需一个**必填项**，其余可选：

| 输入 | 必填 | 说明 |
|---|---|---|
| 概念名称 | ✅ | 如 `Agent`、`大模型的上下文`、`Skill`；英文概念给出中英文 |
| 学习深度 | ❌ | 默认"入门→进阶"，可选"速览（只出精简版）" |
| 目标读者 | ❌ | 默认"编程初学者"，可按需指定 |
| 备注 | ❌ | 已了解的背景、特别想搞懂的点 |

## 3. 生成步骤

对每个概念严格按以下 7 步执行，**不要跳过任何一步**：

1. **澄清概念**：确认概念名称，必要时让用户补全（例如"上下文"指上下文窗口还是上下文学习）。不明确时先按最主流含义处理并在资料中注明。
2. **先自问自答**：在草稿中先用自己的话回答"这个概念是什么？不是什么？"，避免直接照搬资料原文。
3. **收集可核查素材**：联网/本地检索权威资料（官方文档、arXiv 论文、公认技术博客），记录 URL。**禁止编造来源**（见第 6 节）。
4. **按固定结构生成学习资料**：写入 `learning-materials/<概念名>.html`，结构与样式见第 4、5 节。
5. **交叉核对**：把资料中的关键论断与第 3 步来源对照；把易混点与权威定义对照。
6. **自检**：对照第 7 节清单逐项检查并修正。
7. **联动更新仓库**：追加更新 `learning-materials/concept-relationship.md` 的关系说明，并在 `README.md` 的资料清单中登记新条目。

## 4. 输出结构（每份资料的固定章节）

HTML 学习资料必须包含以下章节（编号即顺序），这是本 Skill 的"学习设计"：

1. **学习目标**：学完后能用 1-2 句话说清、能举出应用、能分辨易混点（3 条以内）。
2. **核心问题**：学这个概念前应该先问自己的 2-3 个问题，正文围绕它们展开。
3. **个人解释**：用自己的话讲清楚概念（区别于定义），配一个生活化类比。**不许整段照搬 AI 对话或资料原文**。
4. **核心机制 / 组成**：概念由什么构成、怎么运作，用步骤图/结构图 + 简短条目说明。
5. **具体应用场景**：给出一个具体、可想象的场景，按"输入→过程→输出"讲。
6. **容易混淆的问题 / 使用边界**：至少 2 组辨析（用对比表），说清"不是什么、什么时候不该用"。
7. **自测问题**：3-5 道题，用可折叠块先隐藏答案（`<details>`），检验学习效果。
8. **资料来源**：真实、可点击的链接清单，标注"访问时间"与每条来源的用途。

## 5. 文件与样式规范

- 输出文件：`learning-materials/<概念名>.html`，文件名用英文小写 + 连字符（如 `llm-context.html`）。
- 单文件、无外部依赖：CSS 内联在 `<style>` 中，双击即可在浏览器打开。
- 页面结构：顶部概念标题 + 元信息条 → 章节卡片式正文 → 页脚"生成与人工核查记录"（说明由本 Skill 流程生成、以及做了哪些核查）。
- 浅色主题、清晰排版；正文中文，术语保留英文原文便于检索。

## 6. 资料来源要求（硬性）

- **来源必须真实存在且可核查**：优先官方文档（如 anthropic.com、openai.com）、arXiv、权威技术博客（如 Lil'Log）；可用网络搜索确认 URL 后再写入。
- 每条来源写清楚"为什么引用它"；在资料页脚标注哪些链接已被人工抽查打开、哪些需要读者复核。
- 拿不准的链接宁可不放，**绝不编造 URL、作者或论文号**。
- 概念解释以自己理解为准组织语言，来源用于支撑与溯源，不作复制粘贴。

## 7. 自检要求（交付前逐项打勾）

- [ ] 概念名称与章节齐全（8 个章节都在）；
- [ ] "个人解释"是我自己的话 + 有类比，不是整段搬运；
- [ ] 所有资料来源链接真实（已抽查打开或标注待复核），无编造；
- [ ] 至少 2 组辨析，且覆盖最常被混淆的点；
- [ ] 自测问题答案已核对正确；
- [ ] 文件可在浏览器正常打开、无乱码；
- [ ] 已同步更新 concept-relationship.md 与 README.md；
- [ ] 未包含任何 API Key、密码、个人隐私。

## 8. 示例：本仓库的首次应用

本 Skill 首次被用于生成三份资料，可作为"结构范例"直接参考：

- `learning-materials/agent.html` —— 概念：Agent
- `learning-materials/llm-context.html` —— 概念：大模型的上下文
- `learning-materials/skill.html` —— 概念：Skill

后续学任何新概念，重复第 3 节流程即可，例如："用 concept-explainer 学习 MCP"。
